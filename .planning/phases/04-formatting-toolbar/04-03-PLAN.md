**Step 3: Add undo/redo state polling.**

Observe UndoManager state after each potential change. Add an `.onReceive` on the MarkdownTextEditor view, or use a timer approach.

The cleanest solution: add `undoAction()` and `redoAction()` methods to Coordinator (in MarkdownTextEditor.swift) that also post a notification EditorView observes. But that's complex.

Simpler working approach: add `refreshUndoState()` helper in EditorView that updates canUndo/canRedo from coordinator's textView, and call it from toolbar button actions. Also call it on a short delay after MarkdownTextEditor becomes active.

```swift
private func refreshUndoState() {
    canUndo = coordinator?.textView?.undoManager?.canUndo ?? false
    canRedo = coordinator?.textView?.undoManager?.canRedo ?? false
}
```

Add Coordinator methods for undo/redo (in MarkdownTextEditor.swift):
```swift
func undoAction() {
    textView?.undoManager?.undo()
    text = textView?.text ?? text
}

func redoAction() {
    textView?.undoManager?.redo()
    text = textView?.text ?? text
}
```

**Step 4: Add `.toolbar(placement: .keyboard)` block.**

Inside the `Group { if let doc = document { MarkdownTextEditor(...) } }` body, chain `.toolbar` modifier on the MarkdownTextEditor (not on NavigationStack — the keyboard toolbar must be on the focusable view):

```swift
MarkdownTextEditor(
    text: Binding(...),
    isHighlightingEnabled: !highlightingDisabled,
    coordinatorBinding: $coordinator
)
.ignoresSafeArea(.keyboard)
.toolbar {
    ToolbarItemGroup(placement: .keyboard) {
        // Bold
        Button {
            coordinator?.applyBold()
            refreshUndoState()
        } label: {
            Image(systemName: "bold")
        }
        .tint(.systemBlue)
        .accessibilityLabel("Make text bold")

        // Italic
        Button {
            coordinator?.applyItalic()
            refreshUndoState()
        } label: {
            Image(systemName: "italic")
        }
        .tint(.systemBlue)
        .accessibilityLabel("Make text italic")

        // Bullet
        Button {
            coordinator?.applyBullet()
            refreshUndoState()
        } label: {
            Image(systemName: "list.bullet")
        }
        .tint(.systemBlue)
        .accessibilityLabel("Add bullet to line")

        // Table
        Button {
            coordinator?.insertTable()
            refreshUndoState()
        } label: {
            Image(systemName: "tablecells")
        }
        .tint(.systemBlue)
        .accessibilityLabel("Insert markdown table")

        Spacer()

        // Undo
        Button {
            coordinator?.undoAction()
            refreshUndoState()
        } label: {
            Image(systemName: "arrow.uturn.backward")
        }
        .tint(.systemBlue)
        .opacity(canUndo ? 1.0 : 0.4)
        .disabled(!canUndo)
        .accessibilityLabel("Undo last change")

        // Redo
        Button {
            coordinator?.redoAction()
            refreshUndoState()
        } label: {
            Image(systemName: "arrow.uturn.forward")
        }
        .tint(.systemBlue)
        .opacity(canRedo ? 1.0 : 0.4)
        .disabled(!canRedo)
        .accessibilityLabel("Redo last undone change")

        // Keyboard Dismiss (rightmost — always enabled)
        Button {
            coordinator?.textView?.resignFirstResponder()
        } label: {
            Image(systemName: "keyboard.chevron.compact.down")
        }
        .tint(.systemBlue)
        .accessibilityLabel("Dismiss keyboard")
    }
}
```
