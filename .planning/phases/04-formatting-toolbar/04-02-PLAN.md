Create `MarkdownEditor/FormattingService.swift` as an enum (no instances needed) with static methods that accept a UITextView and perform formatting operations.

**CRITICAL RULES (from research pitfalls):**
1. NEVER use `textView.textStorage.replaceCharacters(in:with:)` — always use `textView.replace(_:withText:)` or `textView.insertText(_:)`
2. NEVER use Swift `String.count` for NSRange math — always cast to NSString first
3. ALWAYS call `undoManager?.beginUndoGrouping()` BEFORE any text modification
4. ALWAYS restore `selectedRange` after text modification

First, add this UITextView extension at the top of FormattingService.swift for UITextRange bridging:

```swift
private extension UITextView {
    func uiTextRange(from nsRange: NSRange) -> UITextRange? {
        guard let start = position(from: beginningOfDocument, offset: nsRange.location),
              let end = position(from: start, offset: nsRange.length) else { return nil }
        return textRange(from: start, to: end)
    }
}
```

Then implement `enum FormattingService` with these five static methods:

**`static func applyBold(to textView: UITextView)`**
- Save `let savedRange = textView.selectedRange`
- Cast `let ns = textView.text as NSString`
- Call `textView.undoManager?.beginUndoGrouping()`
- If `savedRange.length > 0`: extract `ns.substring(with: savedRange)`, build `"**\(selectedText)**"`, call `textView.replace(textView.uiTextRange(from: savedRange)!, withText: wrapped)`, restore `textView.selectedRange = NSRange(location: savedRange.location + 2, length: savedRange.length)`
- If `savedRange.length == 0`: call `textView.insertText("**text**")`, restore `textView.selectedRange = NSRange(location: savedRange.location + 2, length: 4)`
- Call `textView.undoManager?.endUndoGrouping()` and `setActionName("Make Bold")`

**`static func applyItalic(to textView: UITextView)`**
- Same pattern as applyBold but markers are `"*"` not `"**"`, so offsets use 1 not 2, and insertText is `"*text*"` with selectedRange `NSRange(location: savedRange.location + 1, length: 4)`
- setActionName("Make Italic")

**`static func applyBullet(to textView: UITextView)`**
- Save `let savedRange = textView.selectedRange`
- Cast `let ns = textView.text as NSString`
- Find `let lineRange = ns.lineRange(for: savedRange)` — handles LF, CRLF, CR correctly
- Extract `let lineText = ns.substring(with: lineRange)`
- Build `let bulletedLine = "- " + lineText`
- Call `textView.undoManager?.beginUndoGrouping()`
- Replace: `textView.replace(textView.uiTextRange(from: lineRange)!, withText: bulletedLine)`
- Call `textView.undoManager?.endUndoGrouping()` and `setActionName("Add Bullet")`
- Restore: `textView.selectedRange = NSRange(location: savedRange.location + 2, length: 0)`

**`static func insertTable(to textView: UITextView)`**
- Save `let savedRange = textView.selectedRange`
- Define exact table string (3 columns × 2 rows, no leading whitespace):
  ```
  let template = "| Header 1 | Header 2 | Header 3 |\n|----------|----------|----------|\n| Cell 1   | Cell 2   | Cell 3   |"
  ```
- Call `textView.undoManager?.beginUndoGrouping()`
- If `savedRange.length > 0`: replace selection with template using `textView.replace(textView.uiTextRange(from: savedRange)!, withText: template)`
- If `savedRange.length == 0`: insert using `textView.insertText(template)`
- Call `textView.undoManager?.endUndoGrouping()` and `setActionName("Insert Table")`
- Position cursor at start of first cell: `textView.selectedRange = NSRange(location: savedRange.location + 2, length: 8)` (selects "Header 1")
